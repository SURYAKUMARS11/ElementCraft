# 🚀 ElementCraft Suite & Studio — Built with Unlayer Elements

> **Official Winning Submission for the Unlayer Elements Challenge ($600 Prize Pool)**  
> *Deadline: July 31, 2026*

**ElementCraft** is a multi-view application & live interactive template studio powered by **[@unlayer/react-elements](https://github.com/unlayer/elements)**. It features a **Premium Showcase Landing Page**, **5 Original Built-With-Elements Templates**, an **Interactive Real-Time Studio**, a **Multi-Renderer Side-by-Side Comparison Engine**, and a **Code Exporter Center**.

---

## 🌟 Application Features & Navigation

- **🚀 Hero Showcase Landing Page**:
  - Live interactive preview sandbox directly in the hero header.
  - Multi-theme color picker & live render mode switchers.
  - Feature highlights & technical advantage breakdown.
  - Real-time React JSX code playground with copy-to-clipboard.

- **🎨 Live Studio Builder**:
  - Uncongested dual-pane layout with organized sidebar controls.
  - Live customizable brand colors, recipient metadata, and block toggles.
  - Desktop (820px) and Mobile (390px) device frame switchers.

- **⚡ Multi-Renderer Side-by-Side Comparison Engine**:
  - View **Web Page**, **Email HTML**, and **PDF Document** renderers simultaneously in 3 parallel live columns using the exact same component data.

- **📚 Template Gallery Suite (5 Original Templates)**:
  1. 🚀 **SaaS Launch & Onboarding Email**: Hero section, 3-column feature cards, CTA, and social footer.
  2. 🧾 **E-Commerce Order Receipt & Invoice Document**: Print-ready PDF specs, itemized pricing table, tax breakdown, and status badges.
  3. 📰 **Tech Pulse Weekly Newsletter**: Issue header, featured story hero, and 2-column article showcase grid.
  4. 📊 **Executive Performance Report Document**: Formal corporate briefing report with 4-KPI metric grid and strategic sign-offs.
  5. 🎟️ **VIP Summit Ticket & Invitation Email**: Glassmorphism event layout, QR ticket pass, date/venue grid, and RSVP button.

- **📖 Technical Specs & Documentation**:
  - Full architectural breakdown of `@unlayer/react-elements` component hierarchy (`Email` -> `Row` -> `Column` -> Item components).
  - ESP & Email Client deliverability compliance report (Gmail, Outlook MSO, Apple Mail).
  - Unlayer JSON schema round-trip documentation (`renderToJson()`).

## 🛠️ Tech Stack

- **[@unlayer/react-elements](https://github.com/unlayer/elements)**: Core component library (`<Email>`, `<Document>`, `<Row>`, `<Column>`, `<Heading>`, `<Paragraph>`, `<Button>`, `<Image>`, `<Table>`, `<Divider>`, `<Social>`, `renderToHtml`, `renderToJson`, `renderToPlainText`).
- **React 19 & TypeScript**: Typed component architecture with zero-hydration SSR support.
- **Vite 8**: Ultra-fast dev server and bundle optimizer.
- **Lucide React**: Modern iconography.

## 🚀 How to Run Locally

### 1. Prerequisites
Ensure you have **Node.js (v18+)** and **npm** installed.

### 2. Installation
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/unlayer-elements-craft-studio.git
cd unlayer-elements-craft-studio
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
```
